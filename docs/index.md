# arch-mcp architecture

This site contains the arc42 architecture documentation for **arch-mcp**, an MCP server for authoring and browsing architecture documents stored as local Markdown files.

Use the navigation to browse system context, design, runtime scenarios, deployment, architecture decisions, quality requirements, risks, and the glossary. The latest accepted decision on project automation is [ADR-0008](architecture/09-architecture-decisions/adr-0008-use-github-actions-release-please-and-mkdocs-for-project-automation.md).

For installation and development instructions, see the `README.md` file in the repository root.
