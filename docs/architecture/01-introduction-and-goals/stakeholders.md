# Stakeholders

| Stakeholder | Concerns and needs |
|---|---|
| Architecture authors | Capture decisions, concepts, constraints, and views consistently without losing human reviewability. |
| Coding agents | Discover compact, relevant context and use tools whose schemas make valid edits straightforward. |
| Harness maintainers | Launch a local stdio MCP server and register the architecture root. |
| Static-site readers | Browse the Markdown output with visible status, dates, links, and familiar chapter structure. |
| Server maintainers | Evolve collection/chapter definitions and validation while keeping shared file handling testable. |
